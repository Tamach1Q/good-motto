# スマホ投稿UI

白黒・余白を中心に、メモ → 分類内容確認 → 対象選択 → 投稿完了のUIへ更新。

- 小さな補足文を整理。下書き保存とデモシナリオは設定メニューへ移動。
- Good / Mottoで小さな顔が変化。瞬きは5.6秒ごと、入力中の考える反応は1.2秒だけ・最低6.5秒間隔。投稿成功時に白黒の紙吹雪を一度表示。
- 動きを減らすOS設定を尊重。装飾はスクリーンリーダーから除外。
- タップによる新規入力・入力へ戻る・人物検索でフォーカス。Visual Viewportに合わせてキーボード表示時の余白を縮小。初回表示でのキーボード自動表示はブラウザーの制約に従う。
- メモを消して終了する操作は確認ダイアログを挟む。デモの投稿成功は「投稿を試しました」と表示。

認証・所有者付き下書きv3・API契約・投稿結果不明時の再送停止は維持。バックエンド・デプロイ設定・依存パッケージの変更なし。

## 確認

`npm test --prefix frontend` と `npm run build --prefix frontend`。
Chromiumの390px / 320px幅で入力、Good/Motto切り替え、人物・場所の選択、投稿完了、新規入力のフォーカス、横はみ出しのないことを確認。
iOS実機での日本語キーボード・Visual Viewportの操作感は追加確認が必要。
